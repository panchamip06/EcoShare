# 🌱 EcoShare

> A collaborative travel platform that combines trip planning, expense sharing, and sustainable travel insights.

## ✨ Overview

EcoShare is a web application designed to make group travel easier to plan and manage.

It brings trip organization, expense tracking, and sustainability-focused insights together in one place.

## 🚀 Features

- 🗺️ **Trip Planning** — Create and manage trips with other members
- 💰 **Expense Tracking** — Add and manage shared trip expenses
- 🧮 **Expense Splitting** — Track who paid and how expenses are divided
- 📊 **Sustainability Insights** — Visualize travel-related sustainability information
- 👥 **Group Collaboration** — Organize trips with multiple members
- 🔐 **Authentication** — Secure user authentication
- 📧 **Email Integration** — Support for email-based features
